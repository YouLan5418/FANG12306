# 证件要求

## 证件类型

乘车人可使用以下证件购票：
- 中华人民共和国居民身份证（最常用）
- 港澳居民来往内地通行证
- 台湾居民来往大陆通行证
- 外国人永久居留身份证
- 护照

## 实名认证

- 每个乘车人必须完成实名认证后方可购票。
- 实名认证信息包括：姓名、证件类型、证件号码。
- 一个证件号码同一车次只能购买一张车票。
- 儿童可使用户口本或出生医学证明购票。

## 儿童票规定

- 6周岁（含）以下儿童免票，每名成人限带1名免票儿童。
- 6周岁至14周岁儿童购买儿童票，享受半价优惠。
- 14周岁（含）以上儿童购买全价票。
- 儿童票不单独占座，免票儿童不提供座位。
- 如需儿童单独占座，需购买全价票。

## 常见错误码

- 错误码 I0001：证件号码无效。
- 错误码 I0002：实名认证信息不匹配。
- 错误码 I0003：该证件已购买本车次车票。
