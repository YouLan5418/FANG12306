# 退票规则

## 退票手续费

退票手续费按距发车时间阶梯收取：
- 开车前8天（含）以上退票，不收手续费。
- 开车前48小时至8天退票，收取票价5%的手续费。
- 开车前24小时至48小时退票，收取票价10%的手续费。
- 开车前24小时以内退票，收取票价20%的手续费。

## 退票时限

开车后不再办理退票，退票需在发车前办理。
特殊情况：因铁路责任导致列车停运，可在列车停运后2日内全额退票，不收手续费。

## 改签规则

- 开车前48小时（含）以上可改签预售期内的其他列车。
- 开车前48小时以内，可改签票面发站当日其他列车。
- 开车后，旅客仍可改签当日其他列车，但只能在票面发站办理。
- 改签不收手续费，但如有票价差额需补退。

## 常见错误码

- 错误码 B0001：退票时间已过，无法退票。
- 错误码 B0002：退票手续费计算异常。
- 错误码 B0003：该车次不支持退票。
- 错误码 R0001：改签次数超限。
