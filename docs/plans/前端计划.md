旧前端处理策略：

| 部分 | 处理方式 |

## 已完成内容

### 阶段 0：前端初始化

- 新建 `frontend-next/`，旧版 `frontend/` 保持不动。
- 建立 Vite + Vue 3 + TypeScript 工程。
- 接入 Element Plus、Pinia、Vue Router、Axios、ECharts。
- 建立统一 Axios 请求层，自动携带 token，统一处理后端 `Result` 和 401 登录失效。
- 建立 Pinia 登录态，持久化 token、当前用户、真实姓名和角色。
- 建立路由守卫，拦截未登录页面和非管理员访问。
- 建立主布局，支持桌面端侧边栏、手机端底部导航、我的信息入口和右下角智能客服浮窗。

### 阶段 1：用户购票闭环

- 登录接口改为 `/api/user-service/v1/login`，请求字段使用 `usernameOrMailOrPhone/password`。
- 注册页补齐身份证等字段，贴近后端注册 DTO。
- 车票查询页接入 `/api/ticket-service/ticket/query` 和站点下拉数据。
- 购票确认页支持乘车人、座席类型、票种、指定座位号。
- 下单调用 `/api/ticket-service/ticket/purchase`。
- 订单列表接入 `/api/order-service/order/ticket/self/page`，按订单号聚合明细。
- 支付页支持 `ALI_PAY` / `WECHAT_PAY`，并通过支付宝回调接口做本地模拟支付。
- 退款页接入 `/api/pay-service/common/refund`，支持全额退款和选择座位做部分退款。

### 阶段 2：管理后台基础版

- 新增 `frontend-next/src/api/admin.ts`，封装管理后台接口。
- 新增 `frontend-next/src/types/admin.ts`，定义 Dashboard、用户、订单、车次、运营任务类型。
- 管理后台改为 Tabs 工作台：
  - 仪表盘：展示用户数、订单数、车次数、今日订单等指标。
  - 订单管理：支持关键词、状态筛选，支持关闭待支付订单。
  - 用户管理：支持关键词查询，支持普通用户/管理员角色切换。
  - 车次管理：支持车次、起点、终点关键词查询。
  - 运营兜底：支持关闭超时订单、校准 Redis 余票、补偿异常订单。

### 阶段 B：管理后台增强

- 仪表盘新增 ECharts 图表：近 7 日订单趋势、近 7 日支付趋势、订单状态分布。
- 管理接口层新增 `/api/admin/stats/revenue-trend`、`/api/admin/order/stats`、`/api/admin/train/{id}`、`/api/admin/train/publish`。
- 车次管理新增详情抽屉，展示基础信息、经停站和区间票价。
- 车次管理新增一站式发布向导，支持基础信息、经停站、座席票价、车厢容量配置。
- 移动端管理页继续使用单列布局，抽屉在小屏下自动铺满。
- 构建验证：`npm.cmd run build` 已通过。

### 阶段 C：智能客服增强

- 浮窗顶部新增历史会话按钮和新会话按钮。
- 接入后端历史会话接口：
  - `GET /api/customer-service/session/list`
  - `GET /api/customer-service/session/{sessionId}/messages`
  - `DELETE /api/customer-service/session/{sessionId}`
- 支持点击历史会话并回放消息。
- 支持删除历史会话。
- 后端 SSE 契约新增：
  - `thinking`：服务端业务处理进度。
  - `tool_result`：Function Calling 工具执行结果。
  - `sources`：知识库检索来源片段。
- 前端按 ChatGPT 风格分层展示：
  - 普通用户/助手消息。
  - 思考进度。
  - 工具调用参数。
  - 工具返回结果。
  - 信息来源。
- 验证：
  - `npm.cmd run build` 已通过。
  - `mvn.cmd -pl app '-Dtest=SseEmitterSenderTests,FunctionCallingEngineTests,ChatClientTests' test` 已通过，31 个测试全部成功。

### 阶段 D：体验与性能优化

- ECharts 改为 `echarts/core` 按需导入，仅注册折线图、柱状图、饼图、网格、提示框、图例和 Canvas 渲染器。
- Vite 增加手动分包：
  - `vue`
  - `element-plus`
  - `echarts`
- 管理后台页面 JS chunk 从约 1.15MB 降到约 21KB，图表库独立缓存。
- 调整构建告警阈值到 1000KB，当前供应商包体积符合项目依赖实际。
- 构建验证：`npm.cmd run build` 已通过，未再出现大 chunk 告警。
