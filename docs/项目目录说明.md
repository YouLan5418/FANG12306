# 项目目录说明

## 核心目录

| 目录/文件 | 职责 |
| --- | --- |
| `app/` | Spring Boot 主应用，包含用户、票务、订单、支付退款、管理员后台、智能客服和知识库模块。 |
| `framework/` | 项目内通用基础设施模块，包括统一返回/异常、Redis 缓存封装、幂等、分布式 ID。 |
| `dependencies/` | Maven 依赖版本管理模块，统一约束项目依赖版本。 |
| `frontend-next/` | 新版 Vue 3 + Element Plus 前端，当前主要前端入口。 |
| `docker/` | Docker 相关配置，目前包含 RocketMQ broker 配置。 |
| `docker-compose.yml` | 本地 PostgreSQL、Redis、RocketMQ、对象存储等基础设施编排入口。 |
| `config/` | 运行期可热更新配置，目前放智能客服系统提示词。 |
| `scripts/` | 本地验证和运维辅助脚本，例如 Ollama/AI 连通性检查。 |
| `scripts/legacy/` | 早期一次性生成脚本归档，保留供追溯，不作为日常入口。 |
| `jmeter/` | JMeter 压测脚本、压测数据和压测记录。 |

## 文档目录

| 目录/文件 | 职责 |
| --- | --- |
| `API.md` | 当前后端接口契约总文档，保留在根目录方便快速查看。 |
| `docs/design/` | 架构设计、客服设计等长期设计文档。 |
| `docs/plans/` | 阶段计划、实施计划、前端计划、管理端计划等过程型文档。 |
| `docs/setup/` | 本地环境和 AI/Ollama/DeepSeek 配置说明。 |
| `docs/database/` | 数据库结构 SQL 和数据库相关说明。 |
| `docs/knowledge-base-test/` | 智能客服知识库测试数据，包含 Markdown、Word 和生成脚本。 |
| `docs/智能客服压测报告.md` | 智能客服基础压测结果记录。 |

## 本地/历史目录

| 目录/文件 | 职责 |
| --- | --- |
| `frontend/` | 旧版迁移前端，已不作为当前主前端，保留作对照。 |
| `12306/` | 旧前端/迁移残留目录，已被 `.gitignore` 忽略。 |
| `resources/` | 大体量本地数据文件，当前被 `.gitignore` 忽略。 |
| `log/`、`*.log` | 本地运行日志，已忽略，不应提交。 |
| `.env` | 本地真实密钥配置，已忽略；提交示例请使用 `.env.example`。 |
| `.codegraph/`、`.idea/`、`test-results/`、`output/` | 本地索引、IDE、测试和截图产物，均不作为项目源码提交。 |

## 推荐入口

- 启动后端：`app/src/main/java/org/opengoofy/index12306/Index12306Application.java`
- 后端配置：`app/src/main/resources/application.yml`
- 前端启动目录：`frontend-next/`
- API 文档：`API.md`
- 数据库结构：`docs/database/schema-postgresql.sql`
- 智能客服提示词：`config/customer-service-system-prompt.md`
